# Screenshots

Drop images here with these exact filenames and the README picks them up:

| File | What to capture |
|---|---|
| `hero.png` | The landing hero — lime panel, headline, honeycomb |
| `landing.png` | Any of the scroll panels (the yellow converge one is the strongest) |
| `feed.png` | `/feed` signed in as aisha — all three categories visible in one scroll |
| `onboarding.png` | `/welcome` — any of the four panels |
| `tour.png` | `/feed?tour=1` — a coach mark pointing at a real element |
| `post-detail.png` | `/posts/[id]` — the lifecycle timeline and history |
| `profile.png` | `/profile/[id]` — the Buzz Score hero |
| `wallet.png` | `/wallet` — balance, ledger, Scarcity Index chart |
| `trust.png` | `/trust` — the public dashboard |
| `builds.png` | `/builds` — the searchable archive |
| `admin.png` | `/admin/campus` — SLA compliance and recurring risk |

Full-width shots look best at ~1600px wide. The README lays them out two per
row, so consistent aspect ratios matter more than resolution.
